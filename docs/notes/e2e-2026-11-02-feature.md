## Findings

1. **A long description makes a clumsy title.** The run title and the commit title cut at 60 characters, mid-phrase: `Add a public function isAnagram(_ a: String, _ b: String) -> (a)`. Those titles also become the PR's. Cutting at a word boundary helps only a little; a short name for the feature would be better.
2. **A description starting with `#12 ` loses that prefix in the PR title,** because the strip applies to every run title. A test currently asserts this. It should strip only when the first input is a GitHub issue.
